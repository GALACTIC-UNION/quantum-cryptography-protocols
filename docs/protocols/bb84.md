# BB84 Protocol

Bennett & Brassard (1984) prepare-and-measure QKD protocol.

## Reference

Bennett, C. H., & Brassard, G. (1984). Quantum cryptography: Public key distribution and coin tossing. *Proceedings of IEEE International Conference on Computers, Systems and Signal Processing*, 175–179.

## Security Parameters

- Information-theoretic security against collective attacks.
- Key rate bounded by Devetak-Winter formula under finite-key analysis.
- QBER threshold: typically ≤ 11% for secure key generation.
